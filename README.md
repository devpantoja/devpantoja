Diretor de TI em horário comercial. No resto do tempo, a **[CodeGus](https://codegus.com)** — minha fábrica de software de uma pessoa só.

No emprego: time de devs, infraestrutura, GitLab self-hosted e a missão de migrar um legado PHP pra Laravel sem ninguém perceber que o chão trocou de lugar.

Na CodeGus, coisas que coloquei em produção com usuário reclamando de verdade:

- 💰 sistema de gestão e cobrança pra advogados (Laravel + Filament + Asaas)
- 🤖 bot de WhatsApp que atende cliente melhor do que eu
- 🏋️ plataforma de treino pra personal trainer
- 🍕 sistema de senhas e pedidos de pizzaria — o projeto de maior pressão da minha carreira, porque o usuário final está com fome

Gosto de ser dono do ciclo inteiro: do schema do banco ao DNS. Tudo roda na Oracle Cloud em ARM com Terraform e Docker, porque gosto de infraestrutura do jeito que gosto de pizza — boa e barata.
